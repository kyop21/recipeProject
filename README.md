# 초성레시피 (Chosung Recipe)

## Overview
초성레시피는 Android 기반의 레시피 관리 앱으로, 사용자가 엑셀 파일을 이용해 레시피 데이터를 손쉽게 가져오고, Room 데이터베이스에 저장합니다. 최근 업데이트를 통해 UI/UX와 데이터 처리 흐름이 크게 개선되었습니다.

## 주요 기능
- **엑셀 데이터 자동 덮어쓰기**: 새 엑셀 파일을 가져올 때 기존 데이터를 자동 삭제하고 새 데이터를 삽입합니다 (`dao.deleteAll()`).
- **홈 버튼 위치 변경**: 기존 툴바 상단 홈 버튼을 레시피 상세 화면 하단에 큰 노란색 둥근 버튼(`btnGoHome`)으로 이동하여 접근성을 향상시켰습니다.
- **다국어 및 존댓말 지원**: 모든 알림 및 다이얼로그 문구를 정중한 한국어(존댓말)로 업데이트했습니다.
- **아이콘 및 테마**: 고해상도 AI 생성 아이콘 적용 및 다크 모드와 라이트 모드 모두에 어울리는 색상 팔레트 적용.

## 프로젝트 설정
1. **Android Studio**(Arctic Fox 이상)와 **Kotlin 1.8** 환경이 필요합니다.
2. `gradle` 파일을 동기화한 뒤, 프로젝트를 빌드합니다.
3. 실제 기기(Galaxy S10)에서 테스트하려면 USB 디버깅을 활성화하고 `adb`를 통해 디버그 APK를 설치합니다.

## 사용 방법
- 앱을 실행 후 **Import** 버튼을 눌러 엑셀 파일을 선택합니다.
- 기존 레시피가 자동 삭제된 뒤 새 레시피가 데이터베이스에 저장됩니다.
- 레시피 상세 화면 하단의 **Home** 버튼을 눌러 메인 화면으로 돌아갑니다.

## 기여하기

2. 새로운 브랜치를 생성하고 기능을 추가하거나 버그를 수정합니다.
3. 변경 사항을 커밋하고 풀 리퀘스트를 제출합니다.
